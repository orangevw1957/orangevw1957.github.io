# 節目カレンダー PWA 試作品

## 機能
- 誕生日：年齢を自動表示
- 周年・記念日：○周年を自動表示
- 回忌：一周忌、三回忌、七回忌、十三回忌、十七回忌、二十三回忌、二十七回忌、三十三回忌、三十七回忌、五十回忌を自動表示
- 登録データはブラウザのlocalStorageに保存
- Service Workerによるキャッシュ対応

## iPhoneで使う
PWAとして「ホーム画面に追加」するには、HTTPSで配信する必要があります。
このフォルダをHTTPS対応の静的ホスティングにアップロードし、SafariでURLを開いて「ホーム画面に追加」してください。

※この試作品は端末・ブラウザ内保存です。別の端末との同期はまだありません。
